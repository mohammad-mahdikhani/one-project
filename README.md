# استی — خزش قیمت تلگرام و تطبیق با سایت

برنامه و پلاگین برای فروشگاهی که لیست قیمت را از **کانال تلگرام** تامین‌کننده می‌گیرد و همان قیمت را روی سایت می‌گذارد. کارش شبیه جمع‌آوری قیمت در ترب و باسلام است؛ با این فرق که مقصد، فروشگاه خودتان است نه موتور جست‌وجو.

## چه می‌کند

1. کانال عمومی تلگرام را از صفحه `t.me/s/...` می‌خواند.
2. از متن پیام، کد کالا، اسم و قیمت مصرف‌کننده را درمی‌آورد.
3. اول با **کد**، اگر کد روی سایت نبود با **اسم نرمال‌شده** (ک/ک، ی/ی، مدل، الیت، ۴۰۱…) جفت می‌کند.
4. کالاهایی که فقط در کانال هستند جدا نشان داده می‌شوند؛ می‌توانید بسازید یا رها کنید.
5. همان مسیر برای فایل اکسل یا PDF لیست قیمت هم کار می‌کند.
6. اگر ووکامرس وصل باشد، قیمت روی سایت زنده عوض می‌شود.

نمونه واقعی: لیست آکواجوی ۱۴۰۵/۰۷/۱۲. روی سایت ممکن است «تصفیه آب آکواجوی الیت» باشد و در کانال «دستگاه تصفیه آب آکواجوی مدل الیت (ELITE)»؛ استی این دو را یکی می‌گیرد.

## اجرای برنامه

```bash
python3 -m pip install -r requirements.txt
python3 -m ste.app
```

آدرس: [http://127.0.0.1:5055](http://127.0.0.1:5055)

- کانال را مثل `@name` یا `https://t.me/name` بگذارید و «خزش کانال و تطبیق» را بزنید.
- یا تب اکسل را باز کنید و همان فایل لیست قیمت را بدهید.
- برای فروشگاه واقعی، آدرس و کلید REST ووکامرس را در تنظیمات بگذارید و مقصد را «فروشگاه ووکامرس» کنید.

## پلاگین وردپرس

پوشه `wordpress/ste-excel-prices` را در `wp-content/plugins` بگذارید و فعال کنید. از منوی ووکامرس → استی قیمت، اکسل را بارگذاری کنید. خزش تلگرام داخل برنامه پایتون است و می‌تواند مستقیم به همان فروشگاه وصل شود.
