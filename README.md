# استی — اپ سینک قیمت با سایت

یک اپ کوچک برای فروشگاه: سایت ووکامرس را یک‌بار وصل می‌کنید، قیمت را از کانال تلگرام یا اکسل می‌گیرید، بعد با یک دکمه روی سایت می‌گذارید.

## فایل ویندوز — فقط بزنید اجرا شود

**https://github.com/mohammad-mahdikhani/one-project/raw/cursor/ste-excel-price-plugin-7da3/STE-Setup.exe**

این فایل را دانلود و باز کنید. نصب می‌شود، میانبر روی دسکتاپ می‌آید و اپ همان لحظه اجرا می‌شود. پایتون جدا لازم نیست.

## باز کردن از روی سورس

ویندوز: روی `استی.bat` یا `Start-STE.bat` دوبار کلیک کنید.

یا در ترمینال:

```bash
python3 -m pip install -r requirements.txt
python3 -m ste
```

مرورگر روی [http://127.0.0.1:5055](http://127.0.0.1:5055) باز می‌شود.

## سینک با سایت

1. در ووکامرس بروید به **تنظیمات → پیشرفته → REST API → افزودن کلید** و دسترسی **خواندن/نوشتن** بدهید.
2. آدرس سایت، Consumer Key و Consumer Secret را در اپ بگذارید و **تست و ذخیره اتصال** را بزنید.
3. کانال تلگرام را بگذارید (`@name` یا برای تمرین `demo`) یا فایل اکسل/PDF را بدهید.
4. جدول تطبیق را چک کنید.
5. **سینک با سایت** را بزنید.

اگر سایت هنوز وصل نباشد، همان کار روی کاتالوگ داخل اپ انجام می‌شود تا بتوانید تمرین کنید.

تطبیق اول با کد کالا است؛ اگر کد روی سایت نبود، اسم نرمال‌شده را مثل ترب نزدیک‌یابی می‌کند.

## پلاگین وردپرس

پوشه `wordpress/ste-excel-prices` را در `wp-content/plugins` بگذارید. اپ پایتون از REST ووکامرس به همان سایت وصل می‌شود.
